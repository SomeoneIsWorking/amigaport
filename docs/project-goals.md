# Project goals

## G001 — Shared maintained 68000 execution

Provide a title-neutral embeddable 68000 machine owner that executes runtime guest bytes through a
maintained CPU core, while titles own their image formats, devices, services, and native policy.

Success requires complete architectural state and exception semantics, bounded execution, per-image
identity, native overrides with scoped original calls, and representative gameplay conformance for
every released operating-system/architecture pair.

The project does not own a generic Amiga frontend, title data, offline translation, or generated
title code.
